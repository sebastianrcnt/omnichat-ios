## App Review notes

Paste into App Review Information → Notes. Fill in the key in App Review Information → Notes too (there is no
sign-in to enter it into; Apple's "Sign-in required" stays off because OmniChat has no account).

```
OmniChat is a chat client for AI services the user already has ("bring your own key"). There is no OmniChat account, server or in-app purchase; the app is free and open source (GNU GPL): https://github.com/sebastianrcnt/omnichat-ios

HOW TO TEST
1. Launch the app and tap "Add a connection".
2. Choose "Other server", enter the address https://openrouter.ai/api/v1 and this API key (limited test key with a spending cap): <TEST KEY>
3. Save, pick a model in the model menu at the top of a new chat, and send a message. For example:
   • "Search the web for today's weather in Cupertino" (web search with citations)
   • "Plot y = sin(x) for x from 0 to 10 with Python" (on-device Python, a chart appears in the chat)
On a device with Apple Intelligence turned on, "Apple Intelligence" also appears under "Add a connection" and works without a key.

OPTIONAL FEATURES THAT NEED THE USER'S OWN ACCOUNTS
• "ChatGPT account" uses OpenAI's Sign in with ChatGPT for open-source, locally hosted apps and needs a ChatGPT account.
• "Anthropic" needs an Anthropic API key.
• SSH connects only to servers the user adds, and asks before running each command.

ABOUT CODE EXECUTION (2.5.2, 4.7)
• Python runs in a WebAssembly interpreter (Pyodide) bundled in the app, inside a sandboxed web view. All Python packages are bundled; nothing is downloaded. The code is written for the user's request and cannot change the app's features.
• Packages are files the user imports: instructions, declarative HTTP tools and JavaScript tools that run in a sandboxed web view. They contain no native code, and there is no package store in the app.

PRIVACY
The app collects no data. Messages go from the device directly to the service the user chose. API keys are stored in the Keychain. Privacy policy: https://sebastianrcnt.github.io/omnichat-ios/privacy/
```

**Contact:** the developer account's name, phone and email.

## App Store Connect answers

- **App Privacy:** Data Not Collected.
- **Sign-in required:** no.
- **Price:** free. **Availability:** all territories except the EU member states and mainland China.
- **Age rating:** answer the questionnaire as is. The app has unrestricted web access and AI-generated content, so expect
  a higher rating; that is fine for a tool like this.
- **Export compliance:** `ITSAppUsesNonExemptEncryption` is NO in Info.plist. The app uses HTTPS from the OS and, for SSH,
  OpenSSL's standard algorithms (no proprietary encryption).
- **Content rights:** the app doesn't contain third-party content it doesn't have rights to; answer no.
