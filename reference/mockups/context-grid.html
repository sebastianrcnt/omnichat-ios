200칸 격자. 창이 커도 비어 보이지 않게 자동 배율을 써요. 항목을 누르면 그 칸만 강조돼요.
Context
자동 배율: 사용량이 창의 25% 미만이면 격자가 창 전체가 아니라 "사용량의 약 2배 되는 깔끔한 크기"(64k, 128k, 256k…)를 보여줘요. 아래 얇은 막대가 실제 창에서 그 구간이 어디인지 알려줘요. 사용량이 커지면 배율이 바뀌면서 칸이 다시 채워지는 애니메이션이 나와요.

요약 지점: 창 90%에 해당하는 칸부터 주황 테두리. 배율 구간 안에 들어올 때만 보여요.
순서: 시간순 대신 종류별로 묶어서 채워요(시스템 → 도구 → 메시지 → 웹 → 생각 → 이미지).
